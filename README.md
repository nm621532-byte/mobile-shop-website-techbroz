# 📱 PhoneKart — Mobile Shop Website (HTML + CSS + JS)

Ek simple mobile phone store website: phone cards, **Buy Now** button aur cart counter. 
Video mein pehle basic site banayi, phir live redesign kiya: dark mode, purple glow cards, 2-column grid, gradient buttons, 2 naye phones (Pixel 9 + OnePlus 13) aur ek Diwali Sale offer banner.

## Kaise chalayein
1. Repo download karo (Code → Download ZIP) ya `git clone https://github.com/nm621532-byte/mobile-shop-website-techbroz.git`
2. `index.html` browser mein kholo. Bas! Koi install nahi chahiye.

## Files
- `index.html` — page ka structure (naam, cart, offer, shop box)
- `style.css` — design (dark mode, cards, grid, buttons)
- `script.js` — phones ki list, `map()` se cards, cart count

## Naya phone add karna hai?
`script.js` ki `phones` list mein ek line jodo: `["Phone ka naam", "price", "emoji"],`
